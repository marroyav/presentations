# Historical presentation workspaces

These are complete presentation-content snapshots from the September 25, 2026
workstation backup. Both workspaces are retained because they contain different
decks and revisions. PDFs, editable sources, assets and speaker notes remain
together in their original relative layout. Generated TeX caches and nested
Git administrative files are excluded.

The maintained repository and branch are `marroyav/presentations`, `main`.
Historical layouts are retained for recovery and reference; the root Makefile
builds the maintained decks under `decks/`. The legacy repository history is
joined to main and pinned by archive tags. See
[consolidation details](../docs/presentation-consolidation.md).
