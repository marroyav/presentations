# GIZMO Far Detector ground-monitoring guide

Human-facing LaTeX guide for connecting, commissioning, powering, logging, and
operating the DUNE Far Detector ground-reference impedance monitor, including
the controlled response to planned welding shorts.

This is an integration and commissioning draft. It must not be issued as an
electrical work procedure until the Kria software placeholders, released Far
Detector drawings, ORC, calibration, thresholds, work controls, and responsible
approvals have been completed.

Build with:

```sh
make
```

Primary sources are DUNE-doc-35392, 1805, 25365, 27482, and 285. Source links
and the distinction between verified, legacy, and proposed values are included
in the document.
