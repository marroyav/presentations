# SC/DPS repository plan deck

Short discussion deck for the DUNE slow-controls software meeting on
20 August 2026. It proposes a governed repository collection, a naming rule,
and a staged onboarding path for current personal/prototype repositories.

Build from the repository root:

```sh
make
```

Or build locally:

```sh
tectonic --keep-logs --keep-intermediates main.tex
```
