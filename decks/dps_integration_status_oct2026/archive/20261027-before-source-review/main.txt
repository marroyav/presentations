Confirm response times before choosing hardware



So far, I have not found a critical protection function that needs a response below 1 ms.

Each consortium must check the time from detecting a fault to completing the protective
action.

Test sensor, communication, PLC and equipment delays together.
The consortia need to confirm this before procurement. Use a faster local interlock wherever the required response time
demands it.
