\begin{frame}{Five agreements make the interface precise}
  \begin{enumerate}
    \item \textbf{Limits:} the subsystem defines what can damage it.
    \item \textbf{Condition:} the source team owns what it reports.
    \item \textbf{Response:} DPS connects the agreed detector actions.
    \item \textbf{Endpoint:} identify what acts and how we verify it.
    \item \textbf{Failure:} define loss behavior and permission to restart.
  \end{enumerate}
  \medskip
  \textbf{First result:} one boundary map, with an owner on both sides.\par
