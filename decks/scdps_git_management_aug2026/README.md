# SC/DPS Git management deck

Discussion deck for organizing DUNE SC/DPS repositories around the actual
software interfaces: DAQ ZMQ/protobuf paths, OPC-UA bridges, Ignition exports,
emulators, deployment, and release evidence.

Build from the repository root:

```sh
make
```

Or build locally:

```sh
tectonic --keep-logs --keep-intermediates main.tex
```
